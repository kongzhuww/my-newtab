# LogicWeaver 新标签页

一个个人**新标签页仪表盘**浏览器插件(Manifest V3,Edge / Chrome 通用):
打开新标签页就是你的面板 —— 时钟、**B站收藏夹**、**Todoist 今日待办**(可勾选完成)、**GitHub Star**。

首屏是每个用户自己的快捷入口:

- 第一次使用时从浏览器常用网站生成快捷入口。
- 点「编辑入口」可新增、修改、删除网站,并按分组整理。
- 可打开书签抽屉搜索书签,点击导入或拖到指定分组。
- 可上传自己的首屏背景,图片压缩后只保存在扩展本地。
- 向下滚动继续查看 Todoist、天气、书签、B站、GitHub 等内容。
- 桌宠默认使用小尺寸,左键互动/拖动,右键重新选择干员。

## 为什么用插件

插件跑在你自己的浏览器里,可以**直接用你已登录的 B 站 cookie** 调接口 —— 不再有网站版的 412 风控,也不用 VPS 中转。

## 安装(开发者模式加载)

1. 下载/克隆本仓库到本地。
2. 打开 `edge://extensions`(或 `chrome://extensions`)。
3. 右上角打开「**开发者模式**」。
4. 点「**加载解压缩的扩展**」,选中本仓库文件夹。
5. 新开一个标签页,就能看到面板。

## 配置（每个用户填自己的，全部只存本地）

这是**通用**插件,不含任何个人默认值 —— 每项都是「登录 / 配置后才用」:

- **B站收藏夹**:无需配置。只要浏览器登录了 bilibili.com,自动显示**你自己**的收藏夹。
- **小黑盒**:跳转到你登录态下的收藏页。
- 点面板左上「⚙ 设置」填:
  - **城市**(天气,如「武汉」)。
  - **Todoist API Token**(Todoist → Settings → Integrations → Developer)。
  - **GitHub 用户名**(+ 可选 Token)。
  - **VPS 探针地址**(可选,返回 stats JSON 的 HTTPS 接口)。
- **知识库 / GitHub Star 分类**:存插件本地,各用各的。

所有配置保存在浏览器本地(`chrome.storage.local`),不上传任何服务器。未配置的模块会显示「去设置填写」的提示,不影响其它模块。

## 文件

| 文件 | 作用 |
|------|------|
| `manifest.json` | MV3 清单,新标签页覆盖 + host 权限 |
| `newtab.html/.css/.js` | 新标签页仪表盘 |
| `options.html/.js` | 设置页(Todoist / GitHub) |
| `assets/newtab-mountains.png` | 首屏默认背景 |
